# Generated tables

Tab-separated, UTF-8, one header line starting with `#`, generated from the original binaries by
the scripts in `tools/gen/` (never edited by hand).

## palette_sets.tsv
`set` (0..26) · `group` (A|B) · `slot` (0 night, 1 dawn, 2 day, 3 dusk, 4 cloud, 5 gogs) · `pal` · `xft`
File names are relative to BIODATA, lower-cased, with backslashes as in the original.

## page_palettes.tsv
`page` (name as in PAGES.DAT) · `set` (0..26, or -1) · `fixed` (palette file relative to BIODATA, or
empty) · `source` (how the row was determined: `ctor`, `inherit:<page>`, `fixed`, `guess:<why>`)
One row for every page in PAGES.DAT.

## dll_api_wrappers.tsv
Generated by `tools/gen/gen_api_wrappers.py` from the decompiled `BiosGame.dll` and `src/engine/engineapi.h`.
One row for each of the 81 thin wrapper functions of the DLL that send an engine API command
(`SendMessageA(hwnd, 0x8000, code, block)`): `dll_address` · `ghidra_name` · `api_code` (hex) ·
`EngineApi method` · `argument mapping`. The mapping lists, per wrapper argument `p1`, `p2`, ... (declaration
order), the `EngineApi` parameter it feeds (`pN->name`), the out-parameter it receives (`pN<-name`), points
(`pN->x,y`), flags normalised to 0/1 (`pN->name!=0`), then after ` ; ` the constants / conditions the wrapper
applies, the name-length limits it checks (error 1 without sending) and its return convention.
So `FUN_10074880(h, 1)` (`Eng_PlaySound`) becomes `api.PlaySound(h, true)`.
