# Disclaimer

**Biosys Remaster is an unofficial fan project and an homage.** It exists for one reason: so that *Biosys*, a
remarkable game from 1999 that no longer runs on current computers, can be played and appreciated again, and so
that the work of the people who made it is not lost.

## What this project is

- A new program that re-implements the game's engine and rules so that the original data files can be used on a
  modern computer, in the way projects such as ScummVM or OpenMW do for other games.
- A "remaster" only in the sense of optional presentation and comfort features (sharper picture, widescreen,
  cleaner sound, autosave, optional bug fixes). The game's content is the original's, unchanged, and comes from
  your own copy.
- Free of charge and non-commercial. Nobody is paid for it, and it must not be sold.

## What this project is not

- **Not affiliated with, authorised by or endorsed by** JumpStart Solutions Ltd, Take-Two Interactive Software,
  Inc., or any other creator, publisher or rights holder of *Biosys*.
- **Not a copy of the game.** The repository and the downloadable app contain no file of the original game: no
  artwork, sound, film, text file, executable or data file. Without your own copy of the original the app does
  nothing but show its start screen.
- Not a statement about the legal status of the original game. "Abandonware" is not a legal category. The app links

  on the rights holders. If you own the original CDs, you can use images of your own discs instead.

## How it was made

The program was written by studying how the original game works, including static analysis of the original
program files, in order to make the original data usable on current systems (interoperability). The original
program was never run as part of this project and none of its code or data is shipped. The game rules were
re-written to behave the same way; they are this project's own source code, but they necessarily follow the
original's design, numbers and wording, and the names, texts and tables that the game shows remain the
intellectual property of the original rights holders. The screenshots in the documentation show the original
game's artwork and are included for illustration only.
